# Credits

## Blueprints

Every colony blueprint shipped with NeroColonies is an original design generated by
[`tools/gen_blueprints.py`](tools/gen_blueprints.py) from parametric shapes (walls, gable roofs,
domes, towers, spires, arches, colonnades, staircases and bridges). No designs were imported from
other builders, websites or videos.

Licence: original work, same licence as the mod (see [LICENSE](LICENSE)).

To regenerate the catalogue, run `python3 tools/gen_blueprints.py` from the repository root; it
also runs `tools/check_blueprints.py` to validate the output.
