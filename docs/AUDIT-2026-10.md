# NeroColonies audit — October 2026

## Summary

Baseline: `0.2.0-alpha.1` at `6521343`, Core pin `1.13.0`. The mod builds clean (`ecjCheck` and
`:fabric:26.2:build` green). The colony loop works on paper, but three Critical defects keep it
from working in play:

- Nerans are deleted whenever the beacon's chunk reloads (F-01).
- Nerans with nobody nearby either never path or thrash (F-02).
- Construction walls Nerans in (F-03).

On top of those, the default colony name puts a player's name into link payloads and keeps it
after erasure (F-04). One bad list entry can wipe a whole save file (F-05). The app's Colonies tab
is always empty (F-09).

There are 34 findings and 48 suggestions. **Stage R outcome:** 39 Done, 1 Rejected (AUD-40,
reason in the table), and 8 superseded by the vision stages that rebuild the same area. The vision (named, profession-bearing, breeding Nerans) deliberately replaces the
"interchangeable labour" design, so several findings are fixed minimally in Stage R and rebuilt in
Stage B.

## Method

- **Code read:** every file under `common/src/main/java/za/co/neroland/nerocolonies/` named in the
  brief, the shipped datapack content, the lang file, and the loader build scripts.
  Shared code paths below are relative to that package root.
- **Link surface:** this mod's link package, the bridge dispatcher (`ApiDispatcher`, relay prefs),
  and the companion app's summary module, fixtures, notification prefs and telemetry wrappers.
- **Vanilla check:** behaviour was confirmed against the 26.2 sources rather than assumed:
  `Mob.serverAiStep`, `GoalSelector`, `PathNavigation`, `WalkNodeEvaluator`, `Level`.
- **Build:** `:fabric:26.2:ecjCheck :fabric:26.2:build` on the developer machine, green.
- **Runtime:** no game client was available to the auditing agent. The timings in F-21 are
  worked out from default config and shipped content (100-tick colony cycle, 34-block habitat pod,
  2 blocks per supplied cycle, 0.25× unsupplied, a sweep of 2 chunks every 20 ticks). **A hands-on
  Fabric 26.2 playthrough and an MSPT baseline (5 colonies × 40 Nerans) are still owed** before the
  timing and performance claims count as measured.
